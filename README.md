# Agente de IA para Contabilidad

Proyecto PIA para presentar un agente de IA que ayuda a registrar y analizar ingresos y gastos.

## Tecnologías
- HTML
- CSS
- JavaScript

## Función
La aplicación simula un agente de IA que:
- registra movimientos contables
- calcula ingresos, gastos y saldo
- muestra un diagnóstico financiero

## Cómo ejecutar
Abre el archivo `index.html` en el navegador.
